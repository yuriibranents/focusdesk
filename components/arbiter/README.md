# arbiter
Вибір індикації: за подіями автоматів вирішує, що показати на екрані, кільці
й зумері (`ui_cmd_t`). Чистий C, без ESP-IDF. Власник: B. Завдання B7.

## API
`arb_init`, `arb_handle_event`, `arb_tick`, `arb_sync_tasks`, `arb_current`,
`arb_layer`, `arb_layer_name`. Повний опис — у `arbiter.h`.

## Як користуватися (Logic Task)
```c
static arbiter_t s_arb;                       // ~0,7 КБ: static, не на стеку
arb_init(&s_arb);

// на кожну подію (вхідну й вихідну від автоматів) — одна й та сама функція
ui_cmd_t cmd;
if (arb_handle_event(&s_arb, &evt, &cmd)) event_bus_post_ui(&cmd, 0);

// раз на секунду
if (arb_tick(&s_arb, 1, &cmd)) event_bus_post_ui(&cmd, 0);

// після прийому нового розкладу (ts_set_schedule == FD_OK)
if (arb_sync_tasks(&s_arb, ts_schedule(&s_ts)->tasks,
                   ts_schedule(&s_ts)->task_count, &cmd)) event_bus_post_ui(&cmd, 0);
```
UI Task на старті бере початковий вигляд через `arb_current`.

## Пріоритети
| № | Шар | Умова | Екран | Кільце | Звук |
|---|-----|-------|-------|--------|------|
| 1 | TASK | є DUE-задача | TASK, текст задачі, value = кількість DUE | червоне, швидке мигання | швидкий (на кожне нагадування) |
| 2 | ABSENCE | ABSENCE_ALERT, до PRESENCE_BACK | ABSENCE_ALERT, "Повернись!" | оранжеве, повільне мигання | повільний |
| 3 | BREAK | BREAK_DUE, до BREAK_DONE | BREAK, "Час на перерву" | бурштинове, пульс | короткий |
| 4 | FOCUS | сесія йде / пауза / призупинена | FOCUS або FOCUS_PAUSED, назва, залишок | зелений прогрес / синій пульс / сіре | немає |
| 5 | DONE | FOCUS_DONE, 10 с | FOCUS, назва, залишок 0 | зелений пульс | сигнал завершення |
| 6 | IDLE | нічого з вище | IDLE | нейтральний синій | немає |

Вищий шар перекриває нижчий, але нижчий **не губиться**: після зникнення вищого
індикація повертається до нього. Час фокус-сесії тече й під перекриттям.

## Звук
Звук шару лунає один раз, коли шар стає видимим. Якщо шар перекрили, перш ніж
його показали (наприклад, перерва під задачею), звук лунає, коли він уперше
з'явиться. Повернення до шару, що вже звучав, без звуку. Повтор `TASK_DUE`
(кожні 60 с) дає швидкий звук знову.

## Таблиця сценаріїв (кожен покрито тестом)
| Сценарій | Що бачить користувач |
|----------|----------------------|
| Старт фокусу, відлік | FOCUS: залишок щосекунди, прогрес кільця зростає |
| Пауза / відновлення / призупинена | синій пульс (час стоїть) / зелений прогрес / сіре кільце |
| Завершення сесії | банер із сигналом 10 с, потім IDLE |
| Перерва під час фокусу | BREAK; після BREAK_DONE повернення до FOCUS із правильним залишком |
| Задача під час фокусу (E9) | TASK; після "виконано" повернення до FOCUS, час не втрачено |
| Задача під час перерви (E9) | TASK; після "бачу" повернення до BREAK без повторного звуку |
| Дві задачі одночасно | показується найстарша; після "бачу" друга; value = скільки DUE |
| Людина не повернулась (E9) | "Повернись!"; задача її перекриває, після "бачу" вона повертається; зникає по PRESENCE_BACK |
| Перерва в момент завершення сесії (E9) | BREAK зверху; після BREAK_DONE банер завершення зі звуком |
| Новий розклад без задачі, що мигала | arb_sync_tasks прибирає її, екран повертається вниз |

## Відкриті питання
- `EVT_SYSTEM_ERROR` поки не обробляється (екран помилки, «fail-safe» з архітектури) — за потреби окремий шар.
- Кольори й тексти — стартові (`ARB_RGB_*`, `ARB_TEXT_*` у `arbiter.h`), уточнюються з C на макеті.
- Ескалація перерви (F13, Should) не реалізована.
