# bot

Telegram-бот, SQLite, MQTT-клієнт. Власник: D.

## Структура

| Файл | Що робить |
|---|---|
| `db.py` | SQLite: цілі, задачі, підсумки сесій, `get_schedule()` (D2) |
| `parsing.py` | розбір аргументів `/focus`, `/task`; чистий Python |
| `commands.py` | логіка команд: аргументи → текст відповіді; без aiogram |
| `handlers.py` | тонка обгортка aiogram над `commands.py`; фільтр за `ALLOWED_CHAT_ID` |
| `main.py` | запуск бота |
| `mqtt_client.py` | (D4) має віддавати `async def publish_schedule(schedule: dict) -> None` |

## Команди

- `/focus <назва> <тривалість>` — `/focus Англійська 2h`. Тривалість: `2h`, `90m`, `1h30m`, `2г`, `90хв`, `45` (хвилини). Від 1 хв до 10 год.
- `/task <HH:MM> <текст>` — `/task 15:30 Піти в магазин`. Час місцевий, лише сьогодні й лише в майбутньому.
- `/today` — план на сьогодні.
- Назва цілі й текст задачі — до 32 символів (ліміт екрана пристрою).

Після `/focus` і `/task` бот відповідає, що саме збережено і чи розклад надіслано на пристрій.

## Запуск

```
pip install -r bot/requirements.txt
cp .env.example .env          # заповнити BOT_TOKEN і ALLOWED_CHAT_ID
python -m bot.main            # з кореня репозиторію
```

Поки немає `mqtt_client.py`, бот працює, але на кожну команду чесно відповідає
«збережено, але розклад ще не надіслано».
